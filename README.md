# Huffman
## Требования
 - Java 8 или выше
## Компиляция
```
javac Huffman.java
```
## Использование
### Кодирование файла
```
java Huffman compress <input_file> [output_file]
// или
java Huffman c <input_file> [output_file]
```
### Декодирование файла
```
java Huffman decompress <input_file> [output_file]
// или
java Huffman d <input_file> [output_file]
```
## Автоматическое именование
- При кодировании: `file.txt` -> `file.huff`
- При декодировании: `file.huff` -> `file_decoded.txt`
## Структура закодированного файла
Программа использует три формата файлов, выбираемых автоматически:
## 1. Формат для одного символа (Single Character Format)
Используется, когда файл содержит только один уникальный символ.
```
[1 байт]  Маркер формата: 0xFF
[1 байт]  Символ
[4 байта] Количество повторений
[1 байт]  Длина расширения файла (0-255)
[N байт]  Расширение файла (без точки), если длина > 0
```
## 2. Компактный формат (Compact Format)
Используется для файлов с ≤255 уникальными символами и длиной данных <65536 бит.
```
[1 байт]  Маркер формата: 0x01
[1 байт]  Количество уникальных символов N
[для каждого из N символов:
  [1 байт]  Символ
  [2 байта] Частота]
[2 байта] Длина закодированных данных в битах
[M байт]  Закодированные данные (M = ceil(биты/8))
[1 байт]  Длина расширения файла
[L байт]  Расширение файла (без точки), если длина > 0
```
## 3. Стандартный формат (Standard Format)
Используется для больших файлов.
```
[4 байта] Количество уникальных символов N
[для каждого из N символов:
  [1 байт]  Символ
  [4 байта] Частота]
[4 байта] Длина закодированных данных в битах
[M байт]  Закодированные данные (M = ceil(биты/8))
[1 байт]  Длина расширения файла
[L байт]  Расширение файла (без точки), если длина > 0
```
## Примеры тестирования
### Тест 1: 10 одинаковых символов
```
echo -n "1111111111" > test1.txt
java Huffman c test1.txt
java Huffman d test1.huff
diff test1.txt test1_decoded.txt
```
### Тест 2: 20 символов (10, 5, 5)
```
echo -n "11111111112222233333" > test2.txt
java Huffman c test2.txt
java Huffman d test2.huff
diff test2.txt test2_decoded.txt
```
### Тест 3: Бинарный файл
```
javac Huffman.java
java Huffman c Huffman.class
java Huffman d Huffman.huff
cmp Huffman.class Huffman_decoded.class
```
